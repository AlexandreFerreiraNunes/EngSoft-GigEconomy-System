# EngSoft-GigEconomy-System
```Sistema Inteligente de Finanças focado em profissionais da Gig Economy. Utiliza IA para cálculo de metas diárias, previsão de fluxo de caixa e dashboards analíticos para motoristas, entregadores e freelancers.

Equipe:
 • Alexandre Ferreira Nunes -------- Desenvolvedor Front-end Web (React) e Scrum Master
 • Bruno Sousa Preira -------------- Desenvolvedor Back-end e API (Python)
 • Enrique Gil Borges -------------- Banco de Dados (MySQL) e Testes
 • João Emanuel Zilli dos Santos --- Desenvolvedor Mobile (Flutter) e apoio Back-end (Python)


Stack Tecnológica: 
 • Front-end Web: React, Vite e Tailwind CSS.
 • Mobile: Flutter.
 • Back-end: Python utilizando os frameworks FastAPI ou Flask.
 • Banco de Dados: MySQL.
 • Inteligência Artificial: Biblioteca scikit-learn para previsões e sugestões.
 • Ferramentas de Apoio: GitHub (versionamento), Figma (prototipação) e Postman (testes de API).


Metodologia:
 • Framework Scrum: Organização do trabalho em ciclos, com foco em entregas funcionais.
 • Levantamento de Requisitos: Definição clara de necessidades e criação de User Stories.
 • Modelagem e Arquitetura: Uso de diagramas UML para estruturação do sistema.
 • Desenvolvimento e Testes: Ciclo de desenvolvimento integrado com validação contínua e testes de software.


Principais Funcionalidades:
 • Gestão de Metas: Definição de metas mensais de renda pelo usuário.
 • Cálculo Inteligente: Cálculo automático do valor diário necessário para atingir o objetivo financeiro,
   considerando os dias restantes no mês.
 • Registro Ágil: Lançamento rápido de ganhos diários através do aplicativo mobile.
 • Análise Visual: Dashboard completo comparando metas estabelecidas versus valores realizados.
 • IA e Predição: Previsão de fluxo de caixa baseada em padrões históricos e sugestões financeiras estratégicas.
```
